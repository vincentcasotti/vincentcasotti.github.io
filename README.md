# vincentcasotti.github.io

The code behind my personal website and digital workspace. 

## About This Project
This repository hosts my personal landing page. It serves as a central hub for my professional work in digital marketing and ad campaign management, as well as a space to share my offline pursuits—from rock climbing and outdoor recreation to testing out new recipes in the kitchen. 

You can view the live site here: [vincentcasotti.github.io](https://vincentcasotti.github.io) *(Note: Soon to be redirected to vincentcasotti.com)*

## Tech Stack
Built from scratch keeping things as lightweight and fast as possible:
* **HTML5:** Semantic structure.
* **CSS3:** Custom styling with CSS variables and flexbox/grid layouts. No external frameworks.
* **Hosting:** Deployed continuously via [GitHub Pages](https://pages.github.com/).

## Local Development
If you want to run this code locally, you don't need any build tools or local servers. 
1. Clone the repository: `git clone https://github.com/vincentcasotti/vincentcasotti.github.io.git`
2. Open the folder on your machine.
3. Double-click `index.html` to open it in any web browser.
